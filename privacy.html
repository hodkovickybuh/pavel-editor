PAVEL EDITOR — Privacy Policy

PAVEL EDITOR is a visual page editor that runs entirely in your browser.

It collects no data. No analytics, no tracking, no accounts, no network transmission of page content. Everything you edit stays in your browser's own storage (sessionStorage/localStorage) on your machine and is never sent anywhere.

The extension requests access to the pages you visit solely so that, when you click its icon, it can inject the editor into that page. It does nothing on any page until you click the icon.

The only network request the editor makes is a version check against the public jsDelivr API to tell you when an update is available. No personal or page data is included in that request.

Open source: github.com/hodkovickybuh/pavel-editor
