Questions

The ones people actually ask.

Is any of this real?

No. Atelier North is fictional, invented so this page has honest-looking content instead of lorem ipsum. The editor working on it is very real.

Why does the page have deliberate mistakes in it?

Near the bottom there is a marked playground with a contrast failure, a 22px tap target, an image with no alt text and some off-scale spacing. The editor's audit tab should find all of them. If it does not, that is a bug worth reporting.

Can I break the page?

Yes, and nothing happens. Everything the editor does is a preview in your own browser. Refresh and the page is exactly as it was.

How do my changes get into a real codebase?

Press COPY FOR AI and paste the report to whoever builds the site, human or assistant. On a local project with the bridge running, the same button becomes APPLY TO CODE and the report goes straight there.
